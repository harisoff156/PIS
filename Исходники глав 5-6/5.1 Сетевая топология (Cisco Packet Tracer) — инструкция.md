## 3. Маршрутизация
- BGP AS 65010 (внутренний AS ПАО «Самараэнерго»), пиринг с AS провайдера 64500.
- OSPF area 0 — internal routing между CORE-SW1, CORE-SW2 и DIST-SW-A/B/C.
- Статические маршруты от EDGE-RTR1 в сторону SDWAN-CTRL.
- ACL на ASA-FW1: разрешение трафика office→billing только из VLAN 10; запрет прямого доступа Wi-Fi (VLAN 30) к VLAN 20.

## 4. Сервисы безопасности
- IPSec туннель EDGE-RTR1 ↔ BKP-RTR (резервный ЦОД)
- AAA на CORE/DIST через TACACS+ сервер (имитируется Server-PT с включённым AAA)
- DHCP-сервер на CORE-SW1 (VLAN 10, 30) и на ASA-FW1 (VLAN 50 — DMZ)
- DNS-сервер: имитируется Server-PT в VLAN 20 (samaraenergo.local)
- NTP-сервер: имитируется Server-PT, синхронизация с pool.ntp.org

## 5. Кратко по конфигурации (примеры команд для CORE-SW1)
```
hostname CORE-SW1
vlan 10
 name OFFICE
vlan 20
 name BILLING
vlan 30
 name WIFI
vlan 40
 name IOT
vlan 50
 name DMZ
vlan 60
 name MGMT
!
interface GigabitEthernet1/1
 description trunk to DIST-SW-A
 switchport mode trunk
 switchport trunk encapsulation dot1q
 switchport trunk allowed vlan 10,20,30,40,99
!
interface Vlan10
 ip address 10.10.10.1 255.255.255.0
 ip helper-address 10.10.20.10
 no shutdown
!
interface Vlan20
 ip address 10.10.20.1 255.255.255.0
 no shutdown
!
router ospf 1
 router-id 10.10.10.1
 network 10.10.0.0 0.0.255.255 area 0
!
ip route 0.0.0.0 0.0.0.0 213.171.1.1
```

## 6. Тестовые сценарии для проверки
1. ping с PC1 (VLAN 10) на SRV-PGPRO (VLAN 20) — должен проходить.
2. ping с WAP-1 (VLAN 30) на SRV-PGPRO (VLAN 20) — должен блокироваться ACL.
3. tracert с DMZ-WEB до SRV-ELMA — должен пройти через ASA-FW1.
4. shutdown CORE-SW1 — проверка failover на CORE-SW2 (отключение интерфейсов).
5. show ip ospf neighbor — все Core/Distribution должны видеть друг друга в state FULL.
6. show bgp summary — пиринг с провайдером в state Established.

## 8. Открытие в Cisco Packet Tracer
1. Установить Cisco Packet Tracer 8.2 (https://www.netacad.com/courses/packet-tracer).
2. Создать новую топологию.
3. Расположить устройства по таблицам выше (см. координаты на рисунке 5.1).
4. Подключить устройства согласно перечню соединений (см. drawio-файл «5.1 Сетевая топология ПАО Самараэнерго.drawio»).
5. Сконфигурировать VLAN, OSPF и BGP по приведённым примерам.
6. Сохранить как «5.1 Сетевая топология ПАО Самараэнерго.pkt».
