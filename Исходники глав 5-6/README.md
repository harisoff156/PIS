## Порядок работы со схемами

1. **Cisco Packet Tracer**: 
   - Установить Cisco Packet Tracer 8.2 (https://www.netacad.com/courses/packet-tracer).
   - Воспроизвести топологию по таблице устройств и схеме связей из `5.1 Сетевая топология (Cisco Packet Tracer) — инструкция.md`.
   - Сохранить как `5.1 Сетевая топология ПАО Самараэнерго.pkt`.
   - Экспортировать скриншот в Word (рис. 5.1).

2. **IDEF3 (3.2) и IDEF0 (3.5)**:
   - Открыть .drawio в diagrams.net (онлайн или Desktop).
   - При необходимости адаптировать (изменить названия задач, проверить связи).
   - Экспортировать в формат PNG / SVG / EMF и вставить в Word на соответствующие рисунки.
   - Для MS Visio можно сохранить как .vsdx через File → Export.

3. **Диаграмма Ганта (6.2)**:
   - Открыть `6.2 Гант (MS Project) - проектные работы ИС.xml` в MS Project.
   - Дату начала проекта изменить под актуальный год.
   - Экспортировать диаграмму Ганта (File → Print → Save as PDF) и вставить в Word.

4. **Сетевой граф (6.3) и Орг-логические связи (6.1)**:
   - Открыть .drawio в diagrams.net.
   - Экспортировать в PNG/SVG и вставить в Word.
